# RAG Learnings

This project implements a Retrieval-Augmented Generation (RAG) system with:

- Document retrieval (FAISS / ChromaDB)
- Context filtering for better grounding
- Source attribution
- Reduced hallucination

## Tech Stack
- LangChain
- FAISS / ChromaDB
- Sentence Transformers

## How to Run

```bash
pip install -r requirements.txt
python main.py
